# Urdu Alphabet Flashcards PWA

A simple, installable Progressive Web App designed to help users learn the Urdu alphabet. This application provides interactive flashcards for each letter, displaying its various forms, approximate pronunciation using Devanagari script, and an example word with translation.

## Features

* **Comprehensive Coverage:** Flashcards for the majority of the Urdu alphabet characters.
* **Letter Forms:** View the Isolated, Initial, Medial, and Final forms of each letter in a clear 2x2 grid layout.
* **Devanagari Sound:** Reveal the approximate sound of the letter represented in Devanagari script.
* **Example Words:** See an example Urdu word using the letter, along with its Devanagari transliteration and English meaning.
* **Simple Navigation:** Easy "Previous" and "Next" buttons to cycle through the alphabet.
* **Progress Counter:** Track your progress through the letters with a visible counter.
* **Responsive Design:** Optimized to fit various screen sizes and heights without requiring scrolling within the flashcard itself, providing a more app-like feel.
* **Progressive Web App (PWA):** Installable on compatible devices and usable offline after the first visit.

## How to Use

1.  Open the PWA in a modern web browser (like Chrome, Firefox, Edge, Safari, etc.).
2.  The first letter's flashcard will be displayed.
3.  Use the "Next" and "Previous" buttons to navigate through the alphabet.
4.  Click the "Reveal Details" button to show the approximate Devanagari sound and the example word.
5.  Click the button again (now "Hide Details") to hide them.

## PWA Installation

As a Progressive Web App, you can install this application directly from your browser to your device's home screen or application list.

1.  Open the PWA URL in a compatible mobile or desktop browser.
2.  Look for an "Add to Home Screen", "Install app", or similar option in your browser's menu or address bar.
3.  Follow the on-screen prompts to install.

Once installed, the app can be launched directly from your device and will offer basic functionality even without an internet connection.

## Data Notes

The Devanagari transliterations provided are intended as approximate phonetic guides for pronunciation. Urdu has sounds and nuances that may not be perfectly represented by simple transliteration into other scripts.

The forms provided aim to cover common joinings, but variations and specific ligatures exist in complex typography.
